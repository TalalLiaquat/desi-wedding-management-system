# Desi Wedding Management System Frontend

This frontend is built with React 19, Vite, Tailwind CSS, React Router, Axios, React Hook Form, and Zod.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Notes

The frontend contains pages for home, login, registration, dashboard, vendor details, and a 404 page. Axios is configured to call the backend API under `/api`.
